# Биология — 5 класс

Учебный сайт по 27 темам учебника «Биология. 5 класс. Базовый уровень», серия «Линия жизни», под редакцией В. В. Пасечника (2023). В уроках — подробные объяснения простым языком, термины, примеры, схемы и выводы. Игровых заданий пока нет.

## Опубликовать сайт через GitHub Pages

В репозитории открой [Settings → Pages](https://github.com/Nikverlid/Biology/settings/pages). В разделе **Build and deployment** выбери источник **Deploy from a branch**, ветку **main**, папку **/(root)** и нажми **Save**. После публикации сайт будет доступен по адресу https://nikverlid.github.io/Biology/.

Главная страница — `index.html`. Сайт не требует сборки и внешних библиотек.
